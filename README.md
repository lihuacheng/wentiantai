# 问天台 · 官方介绍网站

> 问天台测试质量管理平台的开源官网，基于纯 HTML/CSS/JS 构建，可直接部署到 GitHub Pages。

## 当前官网内容

- 产品定位与核心功能介绍
- 最新界面截图与快速开始指引
- 平台扩展能力说明
- 1 个月 / 3 个月 / 6 个月产品路线图
- 完整使用说明书入口与测试用例基线链接

## 本地预览

```bash
# 任意静态服务器均可，例如：
npx serve .
# 或
python -m http.server 8000
```

## 部署到 GitHub Pages

1. 进入仓库 Settings → Pages
2. Source 选择 `main` 分支，目录选 `/ (root)`
3. 保存后访问 `https://lihuacheng.github.io/wentiantai`
